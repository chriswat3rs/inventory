# Inventory Control — Prototipo

Prototipo navegable (HTML estático, un solo archivo) de una plataforma de control de inventario: dashboard, inventario por almacén, sincronización, reportes y administración de usuarios.

Todos los datos son ficticios (dummy).

## Ver el prototipo

**https://chriswat3rs.github.io/inventory/**

Para entrar, solo haz clic en la flecha del login: el usuario demo ya viene precargado (`demo@example.com` / `demo2026`). Cualquier usuario y contraseña funcionan.

También puedes descargar `index.html` y abrirlo en el navegador; no requiere instalación.
